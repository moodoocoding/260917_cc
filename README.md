# 5학년 인공지능 리터러시 교과서 개발 자료

‘탐구하며 배우는 인공지능 리터러시5’의 32차시 교육과정 및 학교자율시간 과목 신설 신청서 검토 자료입니다.

## 구성

- `docs/`: 신청서 원본, 교육과정 참고자료, 프레임워크 및 수정사항 MD
- `cc/`: 다른 인공지능 관련 과목의 신청서와 교육과정 참고자료
- `school-autonomy-ai-literacy5-site/dist/`: 신청서를 열람하는 정적 웹페이지
- `school-autonomy-ai-literacy5-site/tools/build_html.py`: 신청서 PDF를 웹페이지로 변환하는 스크립트

## 주요 문서

- [5학년 AI 리터러시 프레임워크](docs/5학년_AI리터러시_프레임워크.md)
- [신청서 추가 수정사항](docs/신청서_추가_수정사항.md)

수정사항 MD는 검토 및 제안 기록입니다. 원본 신청서와 웹 열람본에 모든 수정안이 반영되었다는 뜻은 아닙니다.

임시 검토용 PDF·이미지와 로컬 배포 연결 설정은 저장소에서 제외합니다. 참고자료의 저작권은 각 원저작자에게 있습니다.
